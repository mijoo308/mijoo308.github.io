A short project at NextLab on recognizing table structure and handwritten numbers in scanned documents.

- Extracted table cell contour positions with classical image processing (OpenCV)
- Developed a post-processing algorithm to **fill in cells missed due to light smudging**
- Improved handwriting recognition performance using **Retinex** preprocessing
