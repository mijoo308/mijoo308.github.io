An AI-on-edge robotics project built during my visiting scholarship at Carnegie Mellon University: **JUMO**, a beverage-serving robot on a Jetson Nano-powered Jetbot.

- Assembled the Jetbot and set up the **ROS**-based control stack
- Implemented **real-time SLAM navigation** for moving between serving points
- Built a **speech recognition pipeline** so customers can order by voice
- Integrated robot **motion control** with the perception and dialogue components

A small project, but an end-to-end one — perception, planning, and control running together on edge hardware.
